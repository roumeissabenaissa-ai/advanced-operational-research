# Advanced Operational Research

## Overview

This repository contains the practical work completed for the **Advanced Operational Research (AOR)** module during the 2025–2026 academic year.

### Objective of Operational Research

**Operational Research (OR)** is a field that uses mathematical models, algorithms, and optimization techniques to solve complex decision-making problems.

The main objective is to find **optimal or efficient solutions** while considering constraints such as cost, time, capacity, and available resources.

## Problems and Techniques

| Problem | Methods |
|---|---|
| Knapsack | Greedy, Randomized Greedy, Dynamic Programming |
| TSP | Branch and Bound, Mathematical Optimization |
| VRP | Optimization Solvers, Clustering |
| Vessel Problem | Gradient Descent, Newton-Raphson, SLSQP |

## Main Topics

- **Greedy Algorithms:** Fast heuristic solutions based on local choices.
- **Dynamic Programming:** Exact optimization by solving and storing subproblems.
- **Branch and Bound:** Systematic search with pruning to find optimal solutions.
- **Optimization Solvers:** Mathematical modeling using tools such as Pyomo, GLPK, CBC, and Gurobi.
- **Nonlinear Optimization:** Solving problems with nonlinear objectives or constraints.

## Goal of the Project

The main goal is to **apply, compare, and analyze different optimization techniques** according to the nature and size of the problem, considering solution quality, optimality, and execution time.
